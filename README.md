# AI Translation Workbench

이미지나 텍스트의 영어 원문을 한국어로 번역하고, 초벌 번역을 자연스럽게 다듬고, 사람이 최종 결과를 검수하는 AI 번역 워크벤치다.

## 현재 단계

이 저장소는 docs-first 방식으로 다시 시작한다. 코드를 만들기 전에 번역 흐름, 이미지 텍스트 추출 방식, 번역/정규화 단계, 상태 관리, 커밋 규칙을 먼저 고정한다.

## 핵심 방향

- 1차 목표는 데이터셋 생성이 아니라 실제 번역 작업 흐름을 만드는 것이다.
- 텍스트 입력과 이미지 영역 지정 기반 번역을 지원한다.
- 이미지 텍스트 추출은 영역 crop을 만든 뒤 PaddleOCR 같은 OCR 엔진에 맡긴다.
- 번역은 `번역 단계`와 `정규화 단계`로 나눈다.
- 사람은 OCR 결과와 최종 번역을 검수한다.
- RAG는 용어집, 이전 번역, 문체 규칙을 찾는 참고 장치로 사용한다.
- LoRA 학습 데이터셋 생성과 학습 자동화는 MVP 범위에서 제외하고, 나중에 필요할 때 별도 확장으로 다룬다.
