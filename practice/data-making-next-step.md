# 다음 단계: 답변 생성이 아니라 데이터 제작

지금까지 실험하면서 얻은 결론은 다음과 같다.

## 실험에서 배운 점

작은 로컬 LLM은 비용 없이 연습하기 좋지만, 다음 문제가 있다.

- 긴 답변에서 중국어, 영어, 코드 같은 출력이 섞일 수 있다.
- 말투와 성격을 안정적으로 유지하기 어렵다.
- 모르는 내용도 그럴듯하게 꾸며 말하는 할루시네이션이 생긴다.
- 모델이 만든 답변을 그대로 저장하면 데이터셋이 오염된다.

그래서 이 단계에서는 AI를 지식 생성기로 쓰기보다, 사람이 준 재료를 다듬는 도구로 쓰는 편이 낫다.

## 방향 전환

기존 흐름:

```txt
사용자 질문
→ AI가 알아서 답변
→ 좋은 답변 저장
```

이 방식은 AI가 틀린 사실을 만들면 사람이 계속 검수해야 해서 힘들다.

새 흐름:

```txt
질문
+ 핵심 사실
+ 원하는 말투/형식
→ AI가 답변 초안 작성
→ 사람이 최종 수정
→ 학습 데이터로 저장
```

이 방식은 정답 재료를 사람이 제공하기 때문에 할루시네이션을 줄일 수 있다.

## 답변 교정이란?

답변 교정은 AI가 만든 답을 그대로 믿는 것이 아니다.

사람이 제공한 핵심 사실을 기준으로:

- 틀린 내용을 제거하고
- 없는 내용을 추가하지 못하게 하고
- 원하는 말투와 형식으로 정리하고
- 사람이 마지막으로 고쳐서 저장하는 작업이다.

예시:

```txt
질문:
좋은 답변 데이터가 왜 필요해?

핵심 사실:
- AI는 대화 중 자동으로 학습하지 않는다.
- 좋은 답변 데이터는 나중에 파인튜닝이나 LoRA 학습에 쓸 수 있다.
- 입력과 출력 예시가 많을수록 원하는 스타일을 학습시키기 쉽다.

원하는 말투:
친근한 반말, 3문장 이내
```

교정된 답변:

```txt
좋은 답변 데이터는 AI가 바로 배우기 위해서가 아니라, 나중에 학습시킬 재료로 쓰기 위해 필요해. 좋은 입력과 좋은 출력 예시가 쌓이면 파인튜닝이나 LoRA 학습에 활용할 수 있어.
```

## 이번에 추가한 기능의 의미

새 `제작` 탭은 다음 목적을 가진다.

- 질문을 직접 입력한다.
- 핵심 사실을 사람이 직접 제공한다.
- 원하는 말투와 형식을 지정한다.
- AI는 초안만 만든다.
- 최종 답변은 사람이 직접 고친다.
- 고친 답변만 학습 데이터 후보로 저장한다.

즉, 앱의 중심이 단순 채팅에서 데이터 제작으로 이동한다.

## 앞으로의 기준

앞으로 좋은 데이터로 저장할 답변은 다음 기준을 통과해야 한다.

- 핵심 사실에 없는 내용을 만들지 않는다.
- 질문에 직접 답한다.
- 불필요한 외국어가 섞이지 않는다.
- 말투와 길이가 의도와 맞다.
- 사람이 최종 확인했다.

한 문장으로 정리하면:

```txt
이제 목표는 AI가 정답을 맞히게 하는 것이 아니라, 사람이 통제한 사실을 바탕으로 좋은 학습 데이터를 만드는 것이다.
```
