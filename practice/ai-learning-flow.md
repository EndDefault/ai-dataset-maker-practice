# AI 제작 도구 학습 흐름 정리

이 문서는 지금 만들고 있는 연습용 AI 제작 도구가 무엇을 배우고, 나중에 어떤 방식으로 진짜 학습까지 이어지는지 정리한 기록이다.

## 핵심 정리

지금 단계에서 하는 일은 AI 모델 자체를 바로 학습시키는 것이 아니다.

현재 목표는 사용자가 AI에게 역할과 말투를 부여하고, 대화하면서 좋은 답변을 골라서 나중에 학습 데이터로 쓸 수 있게 모으는 것이다.

```txt
AI 역할 설정
→ AI에게 답변 받기
→ 좋은 답변 고르기
→ 좋은 답변을 데이터셋으로 저장하기
→ 나중에 파인튜닝 또는 LoRA 학습에 사용하기
```

## 1. AI에게 역할을 부여한다

먼저 AI 프로필을 만든다.

- AI 이름
- 역할
- 말투
- 성격
- 금지사항
- 답변 스타일

예를 들면 이런 식이다.

```txt
너는 친절한 번역가다.
사용자에게 자연스러운 한국어 표현을 제안한다.
답변은 너무 길게 하지 않는다.
모르면 모른다고 말한다.
```

이 설정은 실제로는 `system prompt`로 AI에게 전달된다.

즉, AI를 진짜로 새로 학습시키는 것이 아니라, AI가 어떤 태도로 답해야 하는지 지시하는 것이다.

## 2. AI에게 답변을 받는다

사용자가 질문을 입력하면 앱은 다음 정보를 묶어서 AI에게 보낸다.

```txt
사용자 질문
+ AI 프로필
+ 관련 기억
+ 답변 스타일
```

그러면 AI는 이 정보를 참고해서 답변한다.

현재 만든 첫 버전은 아직 진짜 AI API와 연결되어 있지 않다. 지금은 구조를 이해하기 위한 연습용 답변 함수가 들어 있다.

나중에 이 부분을 OpenAI API 같은 실제 AI 호출로 바꾸면 된다.

## 3. 좋은 답변을 사람이 고른다

AI가 답변했다고 해서 모든 답변이 좋은 학습 데이터가 되는 것은 아니다.

사람이 보고 좋은 답변만 골라야 한다.

좋은 답변의 예:

- 말투가 원하는 스타일과 맞음
- 역할을 잘 지킴
- 사용자의 질문에 정확히 답함
- 나중에 다시 써도 될 만큼 자연스러움

별로인 답변의 예:

- 너무 장황함
- 역할과 맞지 않음
- 틀린 정보를 말함
- 말투가 원하는 방향과 다름

그래서 앱에는 `좋은 답변 저장` 같은 기능이 필요하다.

## 4. 저장된 좋은 답변은 두 가지 방식으로 쓸 수 있다

저장된 좋은 답변은 단순한 기록이 아니라, 다음 단계로 이어지는 재료다.

### 방식 A: 참고자료로 넣어서 더 좋은 답변을 유도하기

이 방식은 모델 자체를 바꾸는 것이 아니다.

저장된 좋은 답변, 기억, 규칙을 다음 질문 때 AI에게 같이 보내는 방식이다.

```txt
사용자 질문
+ AI 역할
+ 관련 기억
+ 예전에 좋았던 답변 예시
→ AI 답변
```

이렇게 하면 AI가 예전 좋은 답변의 스타일을 참고해서 더 비슷하게 답할 수 있다.

이 방식은 다음 개념과 연결된다.

- 프롬프트 기반 개선
- 기억 시스템
- RAG
- few-shot examples

중요한 점은, 이 방식은 AI가 진짜로 학습한 것이 아니라는 점이다.

AI가 참고할 정보를 더 잘 넣어줘서 답변을 더 좋게 유도하는 것이다.

## 5. 진짜 학습은 나중 단계다

진짜 학습은 좋은 답변이 충분히 쌓인 다음에 한다.

좋은 답변을 JSONL 같은 데이터셋 파일로 모은 뒤, 그 데이터를 이용해 모델을 학습시킨다.

```txt
좋은 답변 데이터 모음
→ JSONL 정리
→ 파인튜닝 또는 LoRA 학습
→ 새 모델 생성
→ 앱에서 새 모델 사용
```

이때는 모델 자체가 바뀐다.

즉, 이 단계가 진짜 의미의 학습에 가깝다.

## 현재 단계와 나중 단계의 차이

```txt
현재 단계:
AI 역할 + 기억 + 좋은 답변 예시를 이용해서 더 좋은 답변을 유도하는 도구

나중 단계:
좋은 답변 데이터를 모아서 실제 모델을 학습시키는 도구
```

## 한 문장으로 정리

지금 만드는 앱은 AI를 바로 학습시키는 앱이 아니라, AI가 좋은 답변을 하도록 유도하고, 좋은 답변을 골라 나중에 진짜 학습 데이터로 모으는 AI 제작 도구다.
