# 요구사항

## 프로젝트 정의

이 프로젝트는 로컬 환경에서 동작하는 작업 수행형 AI 비서다.

사용자가 자연어로 명령을 입력하면 프로그램이 의도를 분류하고, 파일 읽기, 문서 검색, 에러 분석 같은 작업을 실행한 뒤 결과를 Markdown으로 저장한다.

## MVP 기능

처음 구현할 기능은 3개로 제한한다.

```txt
1. txt 파일 요약
2. 폴더 내 txt/md 문서 검색
3. 에러 메시지 분석
```

## 사용자 시나리오

### 1. 문서 요약

입력:

```txt
uploads 폴더 안에 있는 txt 파일 요약해줘
```

완료 기준:

- 지정한 txt 파일을 읽는다.
- 핵심 내용을 요약한다.
- 결과를 화면에 출력한다.
- `outputs/summary.md`로 저장한다.

### 2. 파일 검색

입력:

```txt
리눅스 자료 중 mount 관련 내용 찾아줘
```

완료 기준:

- 검색 키워드를 추출한다.
- 지정 폴더의 txt/md 파일을 검색한다.
- 관련 파일명과 문단을 출력한다.
- 결과를 Markdown으로 저장한다.

### 3. 코드 오류 분석

입력:

```txt
Unresolved reference 'LocationServices'
Android Studio에서 이 에러가 떠
```

완료 기준:

- 에러 메시지를 분석한다.
- 에러 의미, 원인, 해결 방법, 확인할 파일, 수정 예시를 출력한다.
- 결과를 Markdown으로 저장한다.

## MVP 범위 밖

아래 기능은 나중에 확장한다.

- PDF 처리
- OCR
- 음성 인식
- TTS
- RAG
- 일정 관리
- LoRA 데이터 생성
- React/FastAPI 기반 고도화
