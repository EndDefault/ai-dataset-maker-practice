# 현재 상태

## 한 문장 요약

이미지나 텍스트의 영어 원문을 한국어로 번역하고, 초벌 번역을 자연스럽게 정규화한 뒤 사람이 검수하는 AI 번역 워크벤치를 docs-first로 다시 시작했다.

## 현재 목표

- 프로젝트 방향을 AI 번역 워크벤치로 고정한다.
- 텍스트 입력 번역 흐름을 설계한다.
- 이미지 영역 지정, crop 저장, OCR 추출 흐름을 설계한다.
- 번역 단계와 정규화 단계를 분리한다.
- RAG는 용어집, 이전 번역, 문체 규칙 검색 장치로 정의한다.
- 데이터셋 생성과 LoRA 학습 자동화는 MVP 범위에서 제외한다.
