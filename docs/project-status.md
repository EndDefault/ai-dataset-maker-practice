# 현재 상태

## 한 문장 요약

로컬 LLM과 Python 파일 처리를 이용해 문서 요약, 파일 검색, 코드 오류 분석을 수행하는 로컬 AI 작업 비서를 만든다.

## 현재 목표

- 자연어 명령을 입력받는다.
- 명령 유형을 요약, 검색, 에러 분석 중 하나로 분류한다.
- 작업별 Python 함수를 실행한다.
- 로컬 LLM은 결과 요약과 설명 생성을 맡는다.
- 결과를 화면에 출력하고 Markdown 파일로 저장한다.
