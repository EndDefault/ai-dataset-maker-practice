# AI 학습 노트

## 핵심 구분

```txt
PyTorch/TensorFlow = 학습 도구
Transformers = 모델 사용/학습 라이브러리
PEFT = LoRA 같은 효율적 튜닝 도구
LoRA = 모델 습관을 조정하는 adapter 학습 방식
RAG = 참고 자료 검색 방식
```

## 이 프로젝트에서의 역할

- 지도학습: reviewed JSONL로 LoRA 학습
- 비지도학습: 유사 데이터 검색, 중복 탐지, RAG 임베딩
- 강화학습: MVP 범위 밖. 점수 기반 데이터 선별 정도만 고려

## 현실적인 목표

- 처음부터 대형 모델을 만들지 않는다.
- 기존 작은 모델을 가져와 데이터와 LoRA로 작업 습관을 조정한다.
- RAG는 지식 검색용으로 쓰고, 학습은 reviewed JSONL로 진행한다.

## 주의점

- LoRA는 새로운 지식 저장보다 형식과 습관 학습에 적합하다.
- RAG는 지식을 검색하지만 답변 품질을 보장하지 않는다.
- 코드 검사는 구조와 규칙처럼 확실한 부분을 맡는다.
- 사람 검수는 최종 학습 데이터 품질을 결정한다.
