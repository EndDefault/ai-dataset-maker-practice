# AI 번역 구성 노트

## 핵심 구분

```txt
OCR = 이미지 영역에서 텍스트를 추출하는 입력 준비 단계
번역 AI = 영어 원문을 한국어 초벌 번역으로 옮기는 단계
정규화 AI = 초벌 번역을 자연스러운 한국어로 다듬는 단계
RAG = 용어집, 이전 번역, 문체 규칙을 찾는 참고 검색 방식
사람 검수 = OCR과 최종 번역 품질을 확정하는 단계
```

## 이 프로젝트에서의 역할

- OCR: 영역 crop 이미지에서 원문 추출
- 번역: 영어 원문을 한국어로 초벌 변환
- 정규화: 번역투를 줄이고 자연스럽게 다듬기
- RAG: 용어와 문체 기준 검색
- 사람: OCR 결과와 최종 번역 승인

## 현실적인 목표

- 처음부터 데이터셋 생성기나 학습 자동화 도구를 만들지 않는다.
- 텍스트 번역 MVP를 먼저 만든다.
- 이미지 번역은 영역 지정 crop과 OCR 검수 흐름을 붙인다.
- RAG는 용어집과 이전 번역 검색용으로 쓴다.

## 주의점

- OCR 결과는 틀릴 수 있으므로 사람이 수정할 수 있어야 한다.
- 정규화 단계가 원문 의미를 바꾸지 않게 원문과 초벌 번역을 같이 보여주는 것이 좋다.
- RAG 검색 결과는 정답 보장이 아니므로 출처와 함께 보여준다.
- 데이터셋 생성과 LoRA 학습은 추후 확장으로만 둔다.
