# 용어와 핵심 로직 정리

이 문서는 프로젝트를 이해하는 데 필요한 용어와 핵심 로직을 공부용으로 정리한다. 면접이나 자소서에서 설명할 때 내 말로 풀어 말할 수 있도록 유지한다.

## 파인튜닝

파인튜닝은 이미 학습된 모델에 추가 예시를 학습시켜 특정 말투, 형식, 반응 방식을 더 잘 따르게 만드는 방법이다.

이 프로젝트에서의 의미:

- 새로운 지식을 많이 넣기 위한 목적보다, 원하는 말투와 답변 습관을 안정화하는 목적에 가깝다.
- 좋은 답변 예시를 `messages` 형태로 모아 나중에 학습에 사용할 수 있게 준비한다.

주의할 점:

- 파인튜닝은 최신 정보 저장소가 아니다.
- 자주 바뀌는 지식은 파인튜닝보다 RAG나 검색 기반 구조가 더 적합하다.
- 약한 모델을 갑자기 아주 뛰어난 모델로 만드는 기능은 아니다.

## LoRA

LoRA는 큰 모델 전체를 다시 학습하지 않고, 일부 작은 추가 가중치만 학습하는 방식이다.

이 프로젝트에서의 의미:

- 로컬 환경에서 작은 비용으로 말투나 형식을 실험할 때 후보가 될 수 있다.
- 나중에 JSONL 데이터가 쌓이면 실제 학습 실험 단계에서 검토한다.

## RAG

RAG는 답변 전에 외부 문서나 기억에서 관련 정보를 검색하고, 그 검색 결과를 모델에게 같이 넣어 답하게 하는 방식이다.

이 프로젝트에서의 의미:

- 파인튜닝으로 넣기 어려운 지식, 최신 정보, 개인 문서는 RAG로 다루는 편이 좋다.
- 현재 기억 기능은 RAG의 아주 단순한 출발점처럼 볼 수 있다.

핵심 흐름:

```txt
질문
→ 관련 문서 또는 기억 검색
→ 관련 조각만 프롬프트에 포함
→ AI 답변 생성
```

## JSONL

JSONL은 한 줄에 하나의 JSON 객체를 저장하는 형식이다.

이 프로젝트에서의 의미:

- 학습 데이터 후보를 한 줄씩 저장해 파인튜닝 데이터로 사용하기 쉽게 만든다.

예시:

```jsonl
{"messages":[{"role":"system","content":"..."},{"role":"user","content":"..."},{"role":"assistant","content":"..."}]}
```

## messages 구조

`messages`는 대화형 AI 학습 데이터에서 자주 쓰는 형식이다.

역할:

- `system`: AI가 따라야 할 역할과 규칙
- `user`: 사용자의 질문
- `assistant`: AI가 해야 하는 좋은 답변

이 프로젝트의 핵심 로직:

```txt
AI 프로필
→ 시스템 프롬프트 생성
→ 사용자 질문
→ 검수된 답변
→ messages 배열
→ JSONL export
```

## 시스템 프롬프트

시스템 프롬프트는 AI에게 역할, 말투, 금지사항, 답변 형식을 알려주는 상위 지시문이다.

이 프로젝트에서의 의미:

- AI 이름, 역할, 말투, 성격, 금지사항, 답변 스타일을 합쳐 만든다.
- 관련 기억과 좋은 예시가 있으면 함께 포함한다.

## 할루시네이션

할루시네이션은 AI가 모르는 내용을 사실처럼 그럴듯하게 말하는 현상이다.

이 프로젝트에서의 의미:

- 작은 로컬 모델에서 특히 문제가 되었다.
- 그래서 AI에게 정답 생성을 맡기지 않고, 사람이 핵심 사실을 제공하는 데이터 제작 흐름으로 방향을 바꾸었다.

## 검수

검수는 AI가 만든 초안이나 저장된 답변을 사람이 다시 확인하는 과정이다.

이 프로젝트에서의 의미:

- 학습 데이터에 들어갈 답변은 사람이 최종 책임을 가진다.
- 검수 완료된 데이터만 export하는 구조가 필요하다.

## 핵심 로직: 데이터 제작

```txt
질문 입력
→ 핵심 사실 입력
→ 원하는 말투와 형식 입력
→ AI 초안 생성
→ 사람이 최종 답변 수정
→ 학습 데이터 후보 저장
```

핵심 판단:

- AI는 정답 작성자가 아니라 초안 작성 보조 도구다.
- 최종 데이터 품질은 사람의 검수로 보장한다.

## 핵심 로직: 좋은 예시 저장

```txt
채팅에서 AI 답변 생성
→ 좋은 답변인지 확인
→ 필요하면 사람이 수정
→ system/user/assistant 구조로 저장
```

핵심 판단:

- 좋은 예시는 이후 답변 생성 시 참고 예시로도 사용할 수 있다.
- 좋은 예시가 쌓이면 파인튜닝 데이터 후보가 된다.

## 핵심 로직: 실패 기록

```txt
AI 답변 실패
→ 실패 이유 입력
→ 실패 기록 저장
→ 프롬프트, 모델, 데이터 제작 방식 개선에 활용
```

핵심 판단:

- 실패를 버리지 않고 기록하면 개선 방향을 찾기 쉽다.
- 포트폴리오에서도 문제 발견과 개선 과정을 설명할 수 있다.

## 핵심 로직: 기억 검색

```txt
사용자 질문
→ 저장된 기억 중 관련 내용 찾기
→ 관련 기억을 시스템 프롬프트에 포함
→ AI 답변 생성
```

현재 한계:

- 단순 텍스트 검색 기반이라 데이터가 많아지면 정확도와 속도 문제가 생길 수 있다.

확장 방향:

- 키워드 점수화
- 임베딩 기반 벡터 검색
- RAG 구조
