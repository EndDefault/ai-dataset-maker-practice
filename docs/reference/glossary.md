# 용어 정리

## PyTorch

딥러닝 모델을 학습하고 실행하기 위한 Python 기반 프레임워크.

## TensorFlow

딥러닝 모델 학습과 배포를 위한 프레임워크. 이 프로젝트에서는 PyTorch를 우선한다.

## Transformers

LLM, 번역, 요약 같은 모델을 쉽게 불러오고 학습할 수 있게 돕는 Hugging Face 라이브러리.

## PEFT

전체 모델을 다시 학습하지 않고 LoRA 같은 효율적 파인튜닝을 수행하는 라이브러리.

## LoRA

기존 모델 전체를 다시 학습하지 않고 일부 어댑터를 학습해 말투, 형식, 작업 습관을 조정하는 방법.

## RAG

외부 문서나 데이터에서 관련 내용을 검색해 모델 입력에 참고 자료로 넣는 방식.

## 지도학습

입력과 정답 출력 쌍을 사용해 모델을 학습시키는 방식.

## 비지도학습

정답 없이 데이터의 패턴, 유사도, 군집을 찾는 방식.

## 강화학습

행동에 대한 보상을 기준으로 더 좋은 행동을 학습하는 방식.

## JSONL

한 줄에 하나의 JSON 객체를 저장하는 파일 형식. LLM 학습 데이터에 자주 사용한다.
