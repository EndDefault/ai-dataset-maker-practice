# 버그 수정 기록

버그가 발생하면 재현 조건, 원인, 수정 내용, 회귀 방지 방법을 기록한다.

## 기록 형식

```txt
날짜:
증상:
재현 조건:
원인:
수정 내용:
회귀 방지:
관련 파일:
```

## 2026-06-01 중국어 한자 섞임 답변 저장 방지

증상:

- 작은 로컬 모델이 한국어 답변 중 중국어 한자를 섞어 출력하는 경우가 있었다.
- 이런 답변이 좋은 예시로 저장되면 학습 데이터 품질이 떨어진다.

재현 조건:

- Ollama 로컬 모델로 답변 생성
- 일부 질문에서 중국어 한자가 포함된 답변 생성

원인:

- 작은 모델의 한국어 생성 안정성이 낮고, 말투 제약을 완전히 지키지 못했다.

수정 내용:

- 중국어 한자가 섞인 답변은 좋은 예시 저장을 막도록 처리했다.

회귀 방지:

- 답변 저장 전 품질 검사 규칙을 추가한다.
- 향후 실패 유형으로 분류해 모델과 프롬프트 개선에 사용한다.

관련 파일:

- `src/index.js`
