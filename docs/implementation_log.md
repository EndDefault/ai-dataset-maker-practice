# 구현 이력

구현 과정에서 바뀐 파일, 설계 결정, 트레이드오프를 기록한다.

## 2026-06-01 데이터 제작 도구 1차 구현

변경 요약:

- AI 프로필 기반 시스템 프롬프트 생성
- 기억 기능 추가
- Ollama, OpenAI, practice 제공자 연결
- AI 답변 저장과 수정 저장 기능 추가
- 실패 기록 기능 추가
- 데이터 제작 탭 추가
- JSONL export 기능 추가

설계 결정:

- 작은 로컬 모델이 사실 정확도와 말투 유지에 약하므로, AI가 정답을 완성하는 구조보다 사람이 핵심 사실을 제공하고 AI가 초안을 만드는 구조로 방향을 잡았다.
- 학습 데이터는 파인튜닝에 쓰기 쉬운 `messages` 배열 형태로 저장한다.
- 서버 DB 없이 브라우저 `localStorage`를 사용해 MVP를 빠르게 검증한다.

트레이드오프:

- `localStorage`는 구현이 단순하지만 여러 기기 동기화나 대량 데이터 관리에는 약하다.
- 단순 기억 검색은 구현이 빠르지만 데이터가 많아지면 정확도와 속도 한계가 생길 수 있다.
- JSONL export는 바로 쓸 수 있는 장점이 있지만, 검수 상태가 없으면 품질 관리가 어렵다.
