# 큐레이션 데이터 50개

## 목적

로컬 모델이 대화 중 만든 답변은 질문 의도 이탈, 예시 오염, 냥체 누락 문제가 반복되었다. 그래서 1차 학습 데이터 후보는 모델에게 계속 생성시키지 않고, 직접 검수한 좋은 예시 50개로 기준 세트를 만든다.

## 생성 방법

실행 명령:

```cmd
node scripts\create-curated-state.js
```

생성 결과:

- `data/app-state.json`의 dataset을 50개로 교체한다.
- 각 데이터의 `source`는 `curated`로 저장한다.
- 기존 실패 기록은 유지한다.
- 프로필의 대화 기록은 비워 이전 실패 답변이 다시 프롬프트에 섞이지 않게 한다.

## 데이터 범위

50개 예시는 다음 주제를 포함한다.

- 파인튜닝, RAG, 캐시, 프롬프트
- 좋은 학습 데이터와 검수 기준
- 실패 기록, 수정 저장, 좋은 답변 저장
- 로컬 모델과 Ollama 사용 시 주의점
- JSONL, system/user/assistant 메시지 구조
- 포트폴리오 설명에 필요한 프로젝트 의미

## 품질 기준

- 질문에 첫 문장부터 직접 답한다.
- 답변은 기본 1~2문장으로 제한한다.
- 관련 없는 이전 예시 내용을 끌어오지 않는다.
- 모든 문장은 자연스러운 냥체로 끝낸다.
- 핵심 사실에 없는 내용을 추가하지 않는다.

## 검증

생성 후 다음을 확인했다.

- dataset 50개
- source 전부 `curated`
- profile messages 0개
- assistant 답변 끝맺음 문제 0개
