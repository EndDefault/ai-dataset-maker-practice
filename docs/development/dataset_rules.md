# 번역 기록 규칙

## 좋은 번역 기록 기준

- 입력과 출력의 목적이 분명하다.
- 원문, 초벌 번역, 정규화 번역, 최종 번역이 구분된다.
- 이미지 작업은 원본 이미지와 crop 경로가 남는다.
- OCR 원문과 사람이 수정한 원문이 구분된다.
- 최종 번역은 사람이 검수한 상태를 가진다.
- 참고한 용어집이나 이전 번역이 있으면 출처가 남는다.

## 나쁜 번역 기록 기준

- OCR 오류가 수정되지 않은 채 번역된다.
- 초벌 번역과 최종 번역이 섞여 구분되지 않는다.
- 이미지 crop 경로가 없다.
- 최종 번역 검수 상태가 불명확하다.
- 원문과 번역 방향이 맞지 않는다.

## 검사 기준

- JSON 구조
- 필수 필드
- 이미지 파일/crop 파일 경로
- OCR 텍스트 빈 값
- 번역 텍스트 빈 값
- 상태값
- 사람 검수 여부

## Export 기준

MVP에서는 학습용 데이터셋 export를 만들지 않는다. 필요한 경우 나중에 사람이 검수한 번역 기록만 별도 export 기능으로 확장한다.
