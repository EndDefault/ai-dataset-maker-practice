# 데이터셋 규칙

## 좋은 데이터 기준

- 입력과 출력의 목적이 분명하다.
- 출력은 핵심 사실을 벗어나지 않는다.
- 출력 형식을 일관되게 지킨다.
- 금지어와 금지 표현을 사용하지 않는다.
- 학습하려는 습관이 분명하게 드러난다.
- 너무 비슷한 예시만 반복하지 않는다.

## 나쁜 데이터 기준

- 사실에 없는 내용을 추가한다.
- 출력 형식이 흔들린다.
- 너무 긴 설명이 섞인다.
- 같은 패턴만 반복한다.
- 검수 상태가 불명확하다.
- 최종 답변이 빈 값이거나 너무 짧다.

## 검사 기준

- JSON 구조
- 필수 필드
- system/user/assistant 존재 여부
- 빈 content
- 문장 수
- 금지어
- 상태값

## Export 기준

기본적으로 `reviewed` 상태만 JSONL로 export한다.
