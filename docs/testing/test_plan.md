# 테스트 계획

## 테스트 목표

이 프로젝트의 테스트 목표는 학습 데이터 제작 흐름이 깨지지 않는지 확인하는 것이다. 특히 데이터 저장, 수정, 검수, export 흐름은 파인튜닝 준비와 직접 연결되므로 우선순위가 높다.

## 현재 테스트 방식

현재 자동 테스트는 없다. 수동 테스트로 주요 흐름을 확인한다.

실행 명령:

```cmd
npm start
```

접속 주소:

```txt
http://localhost:5173
```

## 주요 테스트 케이스

### 기본 실행

- 서버가 정상 실행되는지 확인한다.
- 브라우저에서 첫 화면이 열리는지 확인한다.
- 콘솔 오류가 없는지 확인한다.

### AI 프로필

- AI 이름을 바꿀 수 있는지 확인한다.
- 역할, 말투, 성격, 금지사항, 답변 스타일을 수정할 수 있는지 확인한다.
- 수정한 내용이 시스템 프롬프트 미리보기에 반영되는지 확인한다.
- 새로고침 후에도 저장된 값이 유지되는지 확인한다.

### 기억

- 기억을 추가할 수 있는지 확인한다.
- 기억을 삭제할 수 있는지 확인한다.
- 질문과 관련 있는 기억이 시스템 프롬프트에 포함되는지 확인한다.

### 채팅

- `practice` 제공자로 답변을 받을 수 있는지 확인한다.
- Ollama가 실행 중일 때 `ollama` 제공자로 답변을 받을 수 있는지 확인한다.
- OpenAI API 키가 있을 때 `openai` 제공자로 답변을 받을 수 있는지 확인한다.
- 연결 실패 시 앱이 멈추지 않는지 확인한다.

### 답변 저장

- AI 답변을 좋은 답변으로 저장할 수 있는지 확인한다.
- AI 답변을 수정해서 저장할 수 있는지 확인한다.
- 실패 이유를 입력하고 실패 기록으로 저장할 수 있는지 확인한다.
- 중국어 한자가 섞인 답변은 좋은 예시 저장이 막히는지 확인한다.

### 데이터 제작

- 질문, 핵심 사실, 말투 조건을 입력할 수 있는지 확인한다.
- AI 초안을 생성할 수 있는지 확인한다.
- 최종 답변을 수정할 수 있는지 확인한다.
- 최종 답변을 학습 데이터 후보로 저장할 수 있는지 확인한다.

### JSONL Export

- 데이터가 없을 때 export를 막는지 확인한다.
- 데이터가 있을 때 `ai-maker-dataset.jsonl` 파일이 내려받아지는지 확인한다.
- 각 줄이 올바른 JSON인지 확인한다.
- 각 항목에 `system`, `user`, `assistant` 메시지가 있는지 확인한다.

## 앞으로 추가할 테스트

- 검수 완료 데이터만 export되는지 확인
- 데이터 수정 후 export 결과가 바뀌는지 확인
- 데이터 삭제 후 목록과 export 결과에서 사라지는지 확인
- 검수 상태 필터가 동작하는지 확인
- localStorage 데이터가 손상되었을 때 앱이 복구되는지 확인
- Playwright 기반 브라우저 자동 테스트
