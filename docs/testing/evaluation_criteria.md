# 평가 기준

## 데이터 평가

- JSON 구조가 맞는가
- 필수 메시지가 있는가
- 출력 형식을 지켰는가
- 금지사항을 어기지 않았는가
- 핵심 사실 밖의 내용을 추가하지 않았는가
- 학습 목적에 맞는가
- 중복이 과하지 않은가

## 모델 평가

- 원본 모델보다 목표 형식을 더 잘 지키는가
- 말투나 출력 습관이 안정적인가
- 답변이 과하게 짧거나 길어지지 않았는가
- 없는 사실을 만들어내지 않는가
- 같은 테스트 질문에서 개선이 확인되는가
