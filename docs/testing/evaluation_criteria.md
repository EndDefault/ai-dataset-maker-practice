# 평가 기준

## 번역 기록 평가

- 원문과 번역 방향이 맞는가
- OCR 결과가 검수되었는가
- 초벌 번역과 정규화 번역이 구분되는가
- 최종 번역이 자연스러운 한국어인가
- 용어가 일관적인가
- 이미지 작업이면 crop과 원문 영역이 맞는가

## 번역 결과 평가

- 원문 의미를 빠뜨리지 않았는가
- 번역투가 과하지 않은가
- 문맥상 어색하지 않은가
- 문체가 요구와 맞는가
- 사람이 최종 승인할 수 있는가
