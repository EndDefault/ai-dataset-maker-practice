# RAG 설계

## 정의

RAG는 모델을 새로 학습시키는 장치가 아니라, 데이터 제작과 답변 실험에 필요한 참고 자료를 검색하는 장치다.

## 이 프로젝트에서의 역할

- 프로젝트 문서 검색
- 기존 좋은 데이터 검색
- 규칙 문서 검색
- 실험 로그 검색
- 데이터 후보 생성 시 참고 자료 제공

## 기본 흐름

```txt
문서 등록
→ 텍스트 분할
→ 임베딩 생성
→ 벡터 저장
→ 관련 자료 검색
→ 데이터 후보 생성/검수에 참고 자료로 제공
```

## 후보 도구

- FAISS
- ChromaDB
- LlamaIndex
- LangChain

## 주의점

- RAG 결과는 정답 보장이 아니다.
- 검색 결과 출처를 함께 저장해야 한다.
- 검색된 내용을 학습 데이터에 넣기 전 사람이 검수해야 한다.
- MVP에서는 RAG보다 데이터 모델과 학습 파이프라인을 먼저 만든다.
