# RAG 설계

## 정의

RAG는 모델을 새로 학습시키는 장치가 아니라, 번역에 필요한 용어집, 이전 번역, 문체 규칙을 검색하는 참고 장치다.

## 이 프로젝트에서의 역할

- 용어집 검색
- 이전 번역 검색
- 문체 규칙 검색
- 작품/문서별 맥락 검색
- 번역 중 참고 자료 제공

## 기본 흐름

```txt
참고 자료 등록
→ 텍스트 분할
→ 임베딩 생성
→ 벡터 저장
→ 관련 자료 검색
→ 번역/정규화 단계에 참고 자료로 제공
```

## 후보 도구

- FAISS
- ChromaDB
- LlamaIndex
- LangChain

## 주의점

- RAG 결과는 정답 보장이 아니다.
- 검색 결과 출처를 함께 저장해야 한다.
- 검색된 용어와 이전 번역을 그대로 적용하기 전 사람이 확인해야 한다.
- MVP에서는 RAG보다 텍스트 번역 흐름과 상태 저장을 먼저 만든다.
