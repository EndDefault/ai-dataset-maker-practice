# UI 화면 문서

현재 앱은 단일 HTML 화면 안에서 왼쪽 프로필, 가운데 채팅, 오른쪽 작업 패널로 구성된다.

## 전체 레이아웃

```txt
왼쪽 사이드바      가운데 채팅 영역        오른쪽 패널
AI 프로필 목록     메시지 목록             설정 탭
                  채팅 입력창             기억 탭
                                          제작 탭
                                          데이터 탭
```

## 왼쪽: AI 프로필 목록

역할:

- AI 프로필을 선택한다.
- 앞으로 여러 AI 프로필을 관리할 수 있는 기반이 된다.

현재 상태:

- 기본 프로필을 사용한다.
- 프로필별 메시지, 기억, 설정을 저장한다.

## 가운데: 채팅 화면

역할:

- 사용자가 AI에게 질문한다.
- AI 답변을 확인한다.
- 좋은 답변 저장, 수정 저장, 실패 기록을 수행한다.

주요 요소:

- 메시지 목록
- 사용자 입력창
- 전송 버튼
- 답변별 액션 버튼

## 오른쪽: 설정 탭

역할:

- AI 이름, 역할, 말투, 성격, 금지사항, 답변 스타일을 설정한다.
- AI 제공자와 모델을 선택한다.
- 시스템 프롬프트 미리보기를 확인한다.

주요 요소:

- 프로필 입력 필드
- 제공자 선택
- 모델 입력
- 시스템 프롬프트 미리보기

## 오른쪽: 기억 탭

역할:

- AI가 참고해야 할 기억을 추가하고 삭제한다.
- 질문과 관련 있는 기억을 프롬프트에 포함하기 위한 기반 데이터다.

주요 요소:

- 기억 입력창
- 기억 추가 버튼
- 기억 목록
- 기억 삭제 버튼

## 오른쪽: 제작 탭

역할:

- 학습 데이터 후보를 직접 만든다.
- 질문, 핵심 사실, 말투 조건을 입력하고 AI 초안을 생성한다.
- 사람이 최종 답변을 수정한 뒤 저장한다.

주요 요소:

- 질문 입력
- 핵심 사실 입력
- 원하는 말투와 형식 입력
- 초안 생성 버튼
- 최종 답변 입력
- 학습 데이터 후보 저장 버튼

## 오른쪽: 데이터 탭

역할:

- 저장된 좋은 예시와 실패 기록을 확인한다.
- JSONL export를 수행한다.
- 데이터 비우기와 앱 초기화를 수행한다.

현재 한계:

- 저장된 좋은 예시를 수정하거나 삭제할 수 없다.
- 검수 완료 상태가 없다.
- export가 전체 데이터 기준으로만 동작한다.

다음 개선:

- 데이터 항목별 수정 버튼
- 데이터 항목별 삭제 버튼
- 검수 완료 토글
- 검수 상태 필터
- 검수 완료 데이터만 export
