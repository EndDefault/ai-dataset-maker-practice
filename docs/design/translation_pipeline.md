# 번역 파이프라인

## 목표

영어 원문을 한국어 초벌 번역으로 옮기고, 다시 자연스러운 한국어로 정규화한 뒤 사람이 최종 검수한다.

## 텍스트 번역 흐름

```txt
영어 원문 입력
→ 참고 자료 검색
→ 초벌 번역
→ 정규화
→ 최종 번역 수정
→ 번역 작업 저장
```

## 이미지 번역 흐름

```txt
이미지 업로드
→ 텍스트 영역 지정
→ crop 이미지 저장
→ PaddleOCR 실행
→ OCR 결과 수정
→ 초벌 번역
→ 정규화
→ 최종 번역 수정
→ 번역 작업 저장
```

## 단계별 역할

| 단계 | 역할 |
| --- | --- |
| 영역 지정 | 사용자가 번역할 텍스트 영역을 직접 선택 |
| OCR | crop 이미지에서 원문 텍스트 추출 |
| OCR 검수 | 사람이 OCR 오류 수정 |
| 초벌 번역 | 영어 원문을 한국어 의미로 옮김 |
| 정규화 | 번역투를 자연스러운 한국어로 다듬음 |
| 최종 검수 | 사람이 의미와 문체를 최종 확인 |

## LoRA와 학습에 대한 현재 결정

- LoRA 학습 자동화는 MVP 범위에서 제외한다.
- 번역 LoRA와 정규화 LoRA는 추후 확장 후보로만 둔다.
- 지금은 앱 안에서 데이터셋을 자동 생성하지 않는다.
- 필요한 학습 데이터는 별도 작업으로 만들고, 이 앱은 번역 작업 흐름을 우선한다.

## 검사 항목

- OCR 텍스트가 비어 있지 않은가
- OCR 결과를 사람이 확인했는가
- 초벌 번역이 비어 있지 않은가
- 정규화 번역이 비어 있지 않은가
- 최종 번역이 승인되었는가
- 이미지 작업이면 crop 파일 경로가 있는가
