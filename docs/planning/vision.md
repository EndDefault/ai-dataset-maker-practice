# 프로젝트 비전

## 프로젝트 이름

AI Translation Workbench

## 한 문장 정의

이미지나 텍스트의 영어 원문을 한국어로 번역하고, 초벌 번역을 자연스럽게 정규화한 뒤 사람이 검수하는 AI 번역 워크벤치다.

## 만들려는 이유

단순히 문장을 한 번 번역하는 앱은 OCR 오류, 번역투, 용어 불일치, 최종 수정 이력을 관리하기 어렵다. 이 프로젝트는 이미지/텍스트 원문을 번역 작업 단위로 관리하고, OCR 결과와 번역 상태를 사람이 확인할 수 있는 흐름을 만드는 것을 목표로 한다.

## 해결하려는 문제

- 이미지 속 텍스트를 전체 OCR로 처리하면 영역 순서와 문맥이 꼬일 수 있다.
- OCR 결과가 틀린 상태로 번역되면 최종 번역도 흔들린다.
- 초벌 번역과 자연스러운 한국어 정규화는 서로 다른 작업이다.
- 용어집, 이전 번역, 문체 규칙을 매번 사람이 직접 찾아야 한다.
- 데이터셋 생성과 모델 학습까지 한 번에 넣으면 MVP가 과하게 커진다.

## 핵심 원칙

- OCR은 번역기가 아니라 이미지에서 텍스트를 추출하는 입력 준비 단계로 본다.
- 이미지 번역은 전체 자동 OCR보다 사용자가 영역을 지정하고 crop을 저장하는 방식을 우선한다.
- 번역은 `영어 원문 → 한국어 초벌 번역` 단계와 `초벌 번역 → 자연스러운 한국어` 단계로 나눈다.
- RAG는 용어집, 이전 번역, 문체 규칙을 검색하는 참고 장치로 본다.
- 사람 검수는 OCR 결과와 최종 번역 품질을 결정한다.
- 데이터셋 생성과 LoRA 학습은 MVP가 아니라 추후 확장으로 둔다.

## 하지 않을 것

- 처음부터 데이터셋 생성기나 LoRA 학습 자동화 도구를 만들지 않는다.
- OCR 전체 자동화를 MVP 목표로 삼지 않는다.
- RAG를 번역 정확도 보장 장치처럼 사용하지 않는다.
- 검수되지 않은 OCR 결과를 바로 최종 번역으로 확정하지 않는다.
