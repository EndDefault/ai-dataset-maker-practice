# 프로젝트 비전

## 프로젝트 이름

Local AI Training Workbench

## 한 문장 정의

로컬 환경에서 지도학습용 데이터셋을 만들고, 검수하고, PyTorch/PEFT 기반 LoRA 학습과 결과 비교까지 이어가기 위한 AI 학습 워크벤치다.

## 만들려는 이유

단순히 프롬프트를 입력해 답변을 받는 앱은 학습 데이터의 품질, 실험 조건, 실패 원인을 반복해서 관리하기 어렵다. 이 프로젝트는 사람이 통제할 수 있는 JSON 데이터와 검수 흐름을 먼저 만들고, 그 데이터를 실제 LoRA 학습 실험으로 연결하는 것을 목표로 한다.

## 해결하려는 문제

- 학습 데이터 후보가 어떤 기준으로 만들어졌는지 추적하기 어렵다.
- 좋은 데이터와 나쁜 데이터를 구분하는 기준이 흐려지기 쉽다.
- JSONL export와 학습 실험이 분리되어 반복 실험 기록이 남지 않는다.
- LoRA, RAG, 로컬 모델의 역할이 섞이면 프로젝트 목표가 흔들린다.

## 핵심 원칙

- LoRA는 지식 저장소가 아니라 형식, 말투, 작업 습관을 조정하는 학습 결과로 본다.
- RAG는 학습 자체가 아니라 참고 자료 검색 장치로 본다.
- 코드 검사는 구조, 필수 필드, 금지어, 문장 수처럼 확실한 규칙을 맡는다.
- 사람 검수는 최종 학습 데이터 품질을 결정한다.
- 학습은 지도학습 기반 JSONL과 PyTorch/PEFT LoRA를 우선한다.

## 하지 않을 것

- 처음부터 ChatGPT급 모델을 직접 학습하지 않는다.
- 강화학습 기반 LLM 학습은 MVP 범위에 넣지 않는다.
- RAG를 모델 학습의 대체물처럼 사용하지 않는다.
- 검수되지 않은 데이터를 바로 학습에 넣지 않는다.
