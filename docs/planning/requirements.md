# 요구사항

## 사용자 시나리오

### 시나리오 1. 텍스트를 번역한다

사용자는 영어 원문을 입력하고 한국어 초벌 번역을 만든다. 이후 정규화 단계를 거쳐 자연스러운 한국어 번역을 확인한다.

### 시나리오 2. 이미지에서 번역할 영역을 지정한다

사용자는 이미지를 업로드하고 텍스트가 있는 영역을 직접 지정한다. 앱은 지정 영역을 crop 이미지로 저장한다.

### 시나리오 3. OCR 결과를 확인한다

앱은 crop 이미지에 PaddleOCR 같은 OCR 엔진을 적용해 텍스트를 추출한다. 사용자는 OCR 결과를 수정하고 승인한다.

### 시나리오 4. 번역 결과를 검수한다

사용자는 초벌 번역과 정규화 번역을 확인하고 최종 번역을 수정한 뒤 승인하거나 거절한다.

### 시나리오 5. 참고 자료를 활용한다

사용자는 용어집, 이전 번역, 문체 규칙 같은 참고 자료를 등록하고 번역 과정에서 검색해 활용한다.

## 기능 요구사항

- [ ] 텍스트 원문 입력
- [ ] 초벌 번역 실행
- [ ] 정규화 번역 실행
- [ ] 최종 번역 수정
- [ ] 번역 작업 저장
- [ ] 이미지 업로드
- [ ] 이미지 영역 지정
- [ ] 영역 crop 저장
- [ ] PaddleOCR 연동
- [ ] OCR 결과 수정과 승인
- [ ] 번역 상태값 변경
- [ ] 용어집/이전 번역/RAG 참고 검색

## 비기능 요구사항

- [ ] Windows `cmd` 기준으로 실행 가능해야 한다.
- [ ] 로컬 파일 기반으로 시작한다.
- [ ] 원본 이미지와 crop 이미지는 경로로 관리한다.
- [ ] OCR 결과와 번역 결과는 사람이 수정할 수 있어야 한다.
- [ ] MVP는 텍스트 번역을 먼저 만들고 이미지 OCR은 다음 단계로 붙인다.
