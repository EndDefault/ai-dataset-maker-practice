# 요구사항

## 사용자 시나리오

### 시나리오 1. 데이터 후보를 만든다

사용자는 학습시키고 싶은 작업 목적, 입력 조건, 출력 형식을 정의한다. 앱은 이 기준에 맞는 데이터 후보 JSON을 저장한다.

### 시나리오 2. 데이터 후보를 검사한다

사용자는 저장된 후보를 코드 검사 기준으로 확인한다. 필수 필드, 빈 값, 상태값, 금지어, 문장 수 같은 확실한 규칙은 코드가 검사한다.

### 시나리오 3. 학습 데이터로 승인한다

사용자는 후보를 직접 보고 `reviewed` 또는 `rejected` 상태로 바꾼다. 기본 export는 `reviewed` 상태만 포함한다.

### 시나리오 4. LoRA 학습을 실행한다

사용자는 reviewed JSONL을 선택하고 PyTorch/PEFT 기반 학습 스크립트로 LoRA adapter를 만든다.

### 시나리오 5. 결과를 비교한다

사용자는 원본 모델과 LoRA 적용 모델의 답변을 같은 질문으로 비교하고 실험 로그에 남긴다.

- [ ] 대용량 모델 결과물은 Git에 넣지 않는다.
