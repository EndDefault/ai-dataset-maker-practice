# 의사결정 로그

## 2026-06-04 AI 번역 워크벤치로 방향 재정의

결정:

- 기존 AI Maker Studio 흐름을 이어가기보다, 새 브랜치에서 AI Translation Workbench로 방향을 재정의한다.
- 데이터셋 생성과 LoRA 학습 자동화는 MVP 범위에서 제외한다.

이유:

- 기존 프로젝트는 채팅, 프로필, LoRA 생성기, RAG 구상이 섞여 목표가 넓어졌다.
- 새 목표는 이미지/텍스트 원문을 번역하고, OCR 결과와 번역 상태를 사람이 검수하는 흐름으로 더 명확하다.
- 데이터셋은 필요하면 AI와 별도 작업으로 만드는 편이 낫고, 앱 안의 자동 생성 기능은 MVP를 흐린다.
- 지금까지의 시행착오는 버리지 않고, 문서 구조와 의사결정 방식으로 흡수한다.

대안:

- 완전히 새 GitHub 저장소를 만든다.
- 기존 앱을 계속 리팩터링한다.
- 학습 데이터셋 생성기를 중심으로 만든다.

결과:

- 현재 저장소의 새 브랜치에서 번역 워크벤치 docs부터 다시 구성한다.
